# Fun Master Pakistan

A small playable Godot 4 Android game starter project with:
- English/Urdu language toggle
- Offline multiple-choice quiz
- Sliding number puzzle (3x3)
- Best score saved locally
- Daily challenge entry point

## Run on a computer
1. Install Godot Engine 4.x (standard build).
2. Open Godot Project Manager.
3. Import `project.godot` from this folder.
4. Press F6/F5 or the Play button.

## Android export
1. Install Android Studio / Android SDK and Java 17.
2. In Godot, install matching Export Templates from Editor > Manage Export Templates.
3. Configure Android SDK paths in Editor Settings > Export > Android.
4. Project > Export > Add Android preset.
5. Set a unique package name (for example `com.yourstudio.funmasterpakistan`).
6. Export APK for direct installation.
7. Export AAB for Google Play Console.
